# Pocket Inquisition

**Dragon Age: Inquisition multiplayer, on servers you run.**

Pocket Inquisition is a custom implementation of Dragon Age: Inquisition's multiplayer servers. Host your own private server for the four-player
co-op mode, on your PC, a home server or Docker, and play with your group on it. A Windows launcher and a small in-game plugin point
only the game's multiplayer connection at your server.

## 📥 Get it

- **Players:** download the latest [release](https://github.com/PocketInquisition/Launcher/releases), unzip it anywhere outside the game folder and run `launcher\DaiLauncher.exe`. The launcher's
  tour walks you through hosting or joining.
- **Hosts:** the same download includes the server (`server\dai.exe`); Linux and Docker builds are on the releases page.
- Also on [Nexus Mods](https://www.nexusmods.com/dragonageinquisition) (link to the mod page once published).

## ⚙ What works

- The Multiplayer hub: all 17 characters, ability trees, promotions, crafting, salvage, the store, challenges and leaderboards
- Create Match and Quick Match for up to four players; Proving Grounds; loot, medals and XP
- Import your own EA progress from a recording of your session
- Play together on a home network, through a tunnel, or over the built-in ZeroTier network
- Join codes, player passwords, invite-only servers and a web manager for admins
